### Your Cravings, Your Choice!

## 🌐 Live Project

## About the Project

BiteRush is a modern food ordering web application designed to provide users with a convenient and engaging food browsing experience. It features a visually appealing interface, organized food menus, and dedicated pages for different stages of the food ordering journey.

The project focuses on modern UI/UX design, intuitive navigation, visual consistency, and a seamless browsing experience.

## Key Features

- 🏠 Home Page
- 🔐 User Onboarding and Login
- 🍽️ Organized Food Menus
- 🖼️ High-Quality Food Images
- 🛒 Shopping Cart
- 💳 Checkout Interface
- 📦 Order Tracking Interface
- 👤 User Profile
- 🌙 Consistent Dark Mode
- 📱 User-Friendly Navigation

## Color Palette & Design Style

BiteRush features a modern, dark-only interface with a consistent color palette.

- **Black:** Primary background
- **Purple:** Primary accents and interactive elements
- **White:** Typography and visual contrast
- **Deep Navy Blue:** Supporting backgrounds and interface surfaces

### Design Highlights

- Dark mode across all pages
- Readable typography
- Rounded cards and buttons
- Subtle glow effects
- Consistent layouts and spacing
- Intuitive navigation
- Modern and visually engaging UI/UX
